## 实践与教学边界

练习服务仅绑定 127.0.0.1 随机端口，每条测试创建新的内存数据，关闭即丢弃。不需要真实账号、Token、数据库，不接触生产系统。
教学故障只存在于独立 Python 练习服务。正常实现必须通过；错误接受 17 岁、重复注册和错误返回 200 必须触发断言失败。fixture 错误、跳过、收集失败与缺少断言不计有效检出。

提供的示范与维护测试不是学习者个人成果。DIAGNOSTIC.md 和 EXERCISES.md 要求独立作答、自己的测试、失败复盘与 GitHub 证据。
