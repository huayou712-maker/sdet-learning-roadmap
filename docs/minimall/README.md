## 章节内的查找方法

每个视频表上方均有对应的完整课程名称、可点击的资源入口和完整网盘目录。使用该目录及表内的完整文件名定位视频，按“本组顺序”观看。

霍格沃兹和论坛课程保留原文件中的编号；华测视频列出原文件的数字前缀及本路线学习索引，同时显示完整文件名。P0 为所在阶段优先掌握，P1 为完善练习，P2 为有需求时观看，P3 为当前路线暂缓。

## 清单校验

在仓库根目录执行，检查原始清单一致性、十五章视频对应关系、资源入口、完整目录、练习及文档链接：

```shell
npm ci --ignore-scripts --prefix docs/minimall
npm test --prefix docs/minimall
```

环境要求：Node.js 20 及以上。依赖版本记录在本目录的 `package-lock.json`，GitHub Actions 执行相同校验。
