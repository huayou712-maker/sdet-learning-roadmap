### D2 文字教程

来源：[Docker Compose 教程正文](https://linux.do/t/topic/877671)。按服务配置、环境变量、健康检查、持久化、示例和常用命令的顺序阅读。文中数据库示例使用 PostgreSQL，MiniMall 的 MySQL 连接与数据目录需要按实际数据库配置。

## Prometheus：具体学习安排

来源：[M1 教程正文](https://linux.do/t/topic/503969)。

| 顺序 | 阅读位置与学习主题 | 优先级 | MiniMall 完成标准 |
|---|---|---|---|
| 1 | Prometheus 部署与采集配置 | P1 | 能读取自己的 `prometheus.yml`，说明采集目标与周期，并检查 Targets 状态。 |
| 2 | Exporter 与指标采集 | P1 | 查看自己的 `/metrics` 数据，说明 CPU、内存、网络与磁盘指标的单位。 |
| 3 | Grafana 数据源与面板 | P1 | 接入自己的 Prometheus，查看相同测试时段的资源变化。 |
| 4 | 告警规则 | P2 | 使用自己的测试服务验证目标不可用告警；通知认证信息由本人配置。 |

教程采用 Linux `node_exporter`。采集 Windows 主机指标时使用对应 Windows Exporter；采集 Linux 环境时使用 Node Exporter。平台说明见 [Prometheus Exporter 官方指南](https://prometheus.io/docs/guides/node-exporter/)。

运行与查询参照 [Prometheus 入门文档](https://prometheus.io/docs/prometheus/latest/getting_started/)；数据源配置参照 [Grafana Prometheus 文档](https://grafana.com/docs/grafana/latest/datasources/prometheus/)。练习只使用自己的测试服务与配置，不复制帖子中的服务器地址或认证信息。
