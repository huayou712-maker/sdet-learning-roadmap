- 完成嵌套 JSON、整体结构、数据库结果及权限检查；验证错误和过期 Token、越权访问、多测试环境。
- 完成 Docker 安装、容器及镜像管理、服务连接、MySQL 数据持久化与 Jenkins 环境部署。
- 完成 Prometheus 安装、指标采集、查询与 Grafana 数据源配置。
- 对原清单中内容完整性待确认的 16 个文件，继续核验或寻找对应主题的替代资源。
