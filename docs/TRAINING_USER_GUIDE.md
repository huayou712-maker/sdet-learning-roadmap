# 如何使用个人训练台

入口是网站的 `/training`。登录所有者账号后使用；练习和复习的正式状态在 GitHub 的 `content/training/state.json`，作业与排障仍由原内容目录保存。没有记录时为空，不会替你创建成绩。公开仓库里的文件可被访问，不要提交真实账号、Token 或隐私信息。

## 先设计：注册用例台

“用例设计”提供现有注册契约 v1 摘要，完整契约有固定版本链接。先填写前置、输入步骤、状态码、响应、数据状态与设计理由，再展开检查提示。每组最多 20 条；字段填满只表示内容完整，不表示预期正确或测试通过。

确认公开仓库提示后，“提交为 Project 0 作业”创建普通作业迭代；可预览 Markdown，提交后沿原作业页编辑。查看过提示会在作业中注明。这里只设计用例，不运行代码、不改训练或知识点成绩。

## 再实践：提交自己的测试结果

1. 按 `projects/beginner-api-lab/README.md` 准备环境，按 `EXERCISES.md` 编写 `tests/test_registration_practice.py`。
2. 在正常实现上运行独立测试，再用 `selfcheck.py tests/test_registration_practice.py` 分别验证三种故障。环境错误、收集错误、skip 不算检出。默认不带文件参数的 `selfcheck.py` 使用示范测试，不能充当你的作业证据。
3. 把独立测试提交本仓库 GitHub 分支，复制完整 commit SHA。网页只检查该版本存在指定测试文件，不执行或判断代码质量。
4. 在“练习验收”填写基线、三种故障实际结果、复盘与可选的本仓库 CI 运行链接。确认公开仓库提示，再提交。
5. 看见“已提交到 GitHub”与 commit 链接才算正式保存。刷新核对记录；原知识点勾选不会改变。

结果始终标为“学习者自报，未自动验真”。更正时提交新尝试，旧尝试保留，建议采用最新记录。

### 手动核对 CI

已附 CI 链接的记录可点“核对 CI 来源与版本”。服务端只接受已有尝试 ID，固定查询本仓库的 Python beginner lab 工作流；不会触发运行、重跑、下载报告或读本机 Git 凭据。

界面分开显示来源、运行标注的提交、工作流路径、运行轮次/作业状态、静态 selfcheck 声明及 JUnit 产物元数据。来源或版本不匹配则停止后续读取。即使配置声明了个人测试，也不能证明实际 checkout 与条件执行正确；示范自检、全绿和产物名称都不代表测试覆盖或掌握。

报告内容仍未核验，产物也未确认所属重跑轮次。结果只在当前页面内存展示，不写回 GitHub、不升级成绩。公开 Actions API 无令牌查询；配额、404、超时和过期会直接显示，不后台重试。每服务实例最多 3 次/分钟、8 次/小时；一次核对最多 4 个 Actions/工作流请求，另有一次正式训练档案读取。

## 对照：把差异写成排障

“失败对照”选择时间顺序正确的两次已有尝试，对照基线、三种结果、自报复盘与代码/CI 链接。“自报有变化”不是自动确认修复。同 SHA 会明确提醒没有代码版本差异。

点击“准备排障草稿”，填写现象、排查过程、验证结果；根因、修复方案没有证据就留空。分类可从已有排障标签手动选择，也可暂不分类。提交创建普通“进行中”排障记录，证据对照附在验证结果中；不会改旧尝试或自动创建复习卡。之后在详情点“加入复习”。

更换两次来源时，脏输入需要确认才能清空。恢复草稿会校验原尝试和版本仍存在；失效时不恢复、不绑定到别的尝试。

## 复习：先作答，再看答案

从笔记或排障详情点“加入复习”。手动确认问题和参考答案，选择概念解释或代码/排障重做。每篇来源最多一张卡，创建当天到期。

先写“你的作答”，代码题还需实际重做命令和结果，然后展开答案。原回答随即锁定，对照后选择独立答对、需要提示或仍然不会。已显式保存的作答草稿同步保留展开锁定；恢复不会让看过答案的回答重新成为可编辑的独立作答。

间隔按 UTC：失败 1 天、提示 3 天、连续独立答对 3/7/14/30 天；失败或提示重新计数，一张卡一天最多评级一次。暂停不删历史，恢复不重置历史。来源进入回收站后不能评级；来源更新需重新核对题目与答案。

## 今日任务与搜索

“今日任务”默认均衡学习：有实践候选时先安排一项基线阻塞、漏检或当前主线，再补充到期复习。可切换集中复习，恢复原复习优先顺序。时间预算 0–180 分钟，最多三项，可以上移。时间只代表本次投入，不承诺完成；调整不写正式日课、不自动标记掌握。跨日或其他设备更新后点击“获取最新版本”，没有后台通知。

全站搜索增加内容类型筛选与真实命中上下文；长正文的匹配位置可直接看到，高亮按普通文本呈现。原访客权限和删除过滤不变。

## 草稿与失败处理

- 未提交输入默认只在内存。练习、复习、用例设计和排障对照可显式保存/恢复/清除本机草稿；不自动提交。
- 草稿有效期 7 天、单条最多 100000 UTF-8 字节，有 schema 与疑似凭据拦截。过期后不能恢复，但需手动清除浏览器数据；这不是加密保险箱，共享设备建议不要保存。
- 正式快照、复习评级历史、原始复盘和 CI 核验结果不保存到 localStorage。对照草稿只含你的输入与来源 ID/SHA。
- 成功提交仅清除本次拥有的草稿版本，不删其他表单或另一标签页的新草稿。当前输入保留供核对。
- 离开站内页面可以取消；浏览器刷新提示取决于原生支持。前进后退、崩溃不能保证拦截，重要输入先显式保存。
- SHA 冲突/网络中断先获取最新 GitHub 版本核对。原练习请求 ID 继续防重复；新作业/排障结果不确定时锁住重试，先另开记录列表确认没有新增，再手动解锁，避免重复创建。
- 训练容量仍为 100 次练习、100 张卡、每卡 60 次历史、512 KiB；到限停止新增，不裁剪历史。

练习只针对隔离教学服务与合成数据，不向生产网站发起测试、压测或故障注入。
