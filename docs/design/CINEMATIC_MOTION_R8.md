# R8 执行边界：风起关山

## 目标与范围

用户明确将本轮重点改为大胆的动态视觉，停止新增学习功能。首页是江湖入口：山景、书法与风的运动形成一个完整的开场，再自然进入现有学习内容。

基线：`main` / `ce9eccd2a042a19e33a4488a58bd89c4a60feef1`（PR #7 已合并）。本轮分支 `feat/jianghu-cinematic-motion`，交新 PR，不自动 merge。

允许修改：首页展示组件、首页局部动效样式、相关测试与设计文档。必要的图片尺寸声明可以校准，但不替换、降清或远程加载现有素材。

不修改：学习路线、正式笔记/作业/进度、鉴权、安全校验、API、GitHub 存储适配、部署配置、依赖版本。GitHub 仍是唯一正式数据源。仅持久化一个非关键 UI 偏好：用户是否关闭首页动效。

## 设计方案

主题：**风起关山**。面向回到学习站的使用者，页面单一任务是建立江湖氛围并保留原有清晰入口。

- 墨夜 `#1f1b15`：既有首屏底色。
- 宣纸 `#f7f3ea`：内容区，沿用既有视觉体系。
- 日照 `#fff0d1`：艺术标题和光迹。
- 砂金 `#b58a3b`：细线、风尘、悬停反馈。
- 青玉 `#42624b`：既有学习状态，语义不变。
- 朱印 `#742b22`：既有品牌印章，不追加无含义的标签。

字体沿用既有三角色：艺术标题 `STXingkai / 华文行楷`；正文和控件 `Noto Sans SC / Microsoft YaHei`；数值/代码 `Cascadia Code / Consolas`。不下载新字体，不改变正文阅读字号，不加描边或文字阴影。

布局：桌面保留左侧艺术标题、右侧高清山景；移动端保留上图下文，按钮可触达。首屏之后仍是学习入口、行迹、实际指标与档案。

```text
桌面  [ 书法分拍入场 / 原有入口 | 金色剑气穿过山景 / 动效开关 ]
      [ 当前学习入口 ] → [ 十阶行迹 ] → [ 指标 / 笔记 / 档案 ]
移动  [ 高清山景 / 风尘与剑气 / 动效开关 ]
      [ 书法标题 / 原有入口 ]
      [ 原有内容逐段展开 ]
```

签名元素：一道细长、非闪烁的金色剑气沿山势扫过，配合山景缓移和书法分拍入场，形成一次完整的“展卷”开场。不是进度条，也不暗示任何学习成就。

自审：放弃通用粒子星空、彩色霓虹和全站卡片翻转。保留暖纸底，因为这是用户既定江湖设计，不是重新套模板。剑气是主角；正文不漂浮，表单不移动。档案封面的光泽和滚动入场使用同一套节奏，不追加第二套视觉主题。

## 动效与性能边界

1. 保留原生滚动、鼠标和键盘操作；不劫持滚轮、不锁滚动、不加鼠标尾巴、音频、视频或 WebGL。
2. 内容默认可见。JavaScript、IntersectionObserver、存储不可用时保留静态首页；装饰失效不能阻断链接或图片。
3. 尊重 `prefers-reduced-motion`，优先于手动开启。提供明确的动效开关；关闭后首屏、滚动与悬停新增位移全部停止。
4. 仅桌面精细指针启用有限幅度视差；移动端无指针跟随，减少粒子数量。指针更新按请求合并到单个 animation frame，不设置持续 JS 渲染循环。
5. 页面隐藏或首屏离开视口后暂停环境动画、解绑相关监听并取消待处理帧；卸载时清理 observer、监听器和帧。
6. 背景运动使用 transform/opacity；SVG 剑气描边只做有限次开场。滚动入场每个区块最多一次，不先隐藏内容等加载。
7. 不新增外部网络请求、动画依赖、图片副本或大字体包。仍验收 Next/Image 的高清与 lazy loading。

## 技术参考

- [MDN Intersection Observer](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API)：按视口交叉管理一次性展开和离屏暂停。
- [MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)：系统减少动态效果优先。
- [web.dev 高性能动画](https://web.dev/articles/animations-guide)：运动优先 transform/opacity，避免布局属性逐帧变化。

这些资料用于实现取舍，不据此宣称所有设备都能达到固定帧率。
