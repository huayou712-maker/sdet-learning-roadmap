# 江湖学习体验 R4 · 执行边界与方案

## 决策

面向测开初学者，在已确认的 R3 字体与江湖视觉上改善日常使用。不重新换皮，不新增学习系统。本轮只做三个页面的展示与交互；正式业务数据仍只以 GitHub Repository 为准。

视觉签名继续是沙漠行者与两行书法首屏。学习区采用安静的任务简报，作品区采用可检查的案例档案。

### 沿用的视觉约束

- 墨褐 `#1f1b15`、暖纸 `#fffcf6`、砂色 `#eee6d8`、赭金 `#79561e`、朱砂 `#8f382b`、玉绿 `#42624b`。
- 首屏华文行楷 400；章标题 Noto Serif SC；正文/UI Noto Sans SC；代码 Cascadia Code / Consolas。均沿用本地字体栈与回退，不复制或分发字体。
- 正文桌面 17px/30px、手机 16px/28px；笔记阅读正文不超过 720px。艺术字不进入表单或长正文。
- 顺序编号只用于真实“学 → 练 → 记”步骤，不给任意卡片加装饰排名。不增加背景视频、粒子或动画依赖。

## 三项交付

### 1. 首页：把下一步说清楚

将重复的当前任务标题和三栏里的任务卡合并为一个学习简报，置于首屏后。展示原推荐任务、交付物和真实知识点/证据计数，验收要求用可键盘操作的原生展开控件。保留完整十阶路线、四项统计、最近笔记、动态和项目。

“学 → 练 → 记”分别指向现有路线、练习指南、笔记入口；访客只看到阅读入口。不将所有任务误标为注册 API 练习，不改变推荐结果或自动标记完成。

```text
电影感首屏（保留 R3）
┌ 当前任务 / 交付与验收 ──────┬ 学 → 练 → 记 ┐
└───────────────────────────┴──────────────┘
十阶学习行迹 → 真实统计 → 最近笔记 / 最近动态 → 项目档案
```

### 2. 笔记：可退出的专注阅读

新增显式“专注阅读”开关，隐藏两侧辅助栏并保持正文栏宽。提供始终可达的退出按钮与 Escape 退出；保留返回知识库的路径。不更改 Markdown、目录锚点、编辑、历史、权限或保存行为。不记录阅读进度，不写 localStorage，刷新后恢复默认。

### 3. 作品集：问题、方法、验证、结果

将已公开项目整理成中文案例档案，沿用已有项目背景、架构设计、测试范围与成果。补充可见的证据清单，明确“链接已提供”不等于“测试已验证”，“必做自评”不等于自动通过。保留源码、报告、演示、排障案例、完整说明与 GitHub 历史。

没有数据时显示缺失，不编造项目、分数、通过率、成果或 CI 状态；私有/删除内容不能出现在公开页面。

## 参考与取舍

- [Exercism 的入门与练习路径](https://exercism.org/docs/using/getting-started)：借鉴从学习到实践的清晰入口，不引入积分、排名或新的课程引擎。
- [GitHub Primer 的渐进展开](https://primer.style/product/ui-patterns/progressive-disclosure/)：将详细验收放进按需展开区域，保留上下文与明确的文字操作。

设计复核：三项都解决真实使用问题，继续沿用原江湖题材。舍弃通用数据大屏、装饰性徽章墙、第二套艺术字体和阅读计分，以免干扰学习或制造虚假完成感。

## 不可越界

不修改学习记录、课程/任务 ID、统计/推荐/评分/复习算法、OAuth、权限、GitHub Adapter、CRUD、SHA 冲突保护、Markdown 安全、凭据拦截、限流、部署或环境变量。不新增正式数据持久化、远程字体或媒体。测试仅使用隔离合成数据。

在 `feat/jianghu-art-ui` 上继续工作，统一 PR 到 main，不重复建 PR、不自动合并。提交与预览不代表生产已更新。

## 验收门槛

1. 新交互覆盖桌面/手机、键盘、访客/Owner，专注模式开关与 Escape；学习计数保持原数据，公开项目不泄露私有记录。
2. 保留高清资源验收及 lazy loading 策略，不等待离屏图片 decode；不 skip、删除测试或增大 timeout。
3. lint、typecheck、unit、build、完整 E2E 全部通过，并查看真实浏览器截图。结果在完成后填写，不预报通过。
4. 推送后检查该提交的 GitHub Actions 与 Vercel 状态；不据本地开发环境宣称生产性能或跨设备字体一致性。

## 后续设计积压（本轮不实施）

- 全站状态：统一加载、空白、错误和冲突提示的下一步操作。
- 上线前：真实网络 LCP/CLS、原生浏览器 200% 缩放、其他设备字体回退；统一书法字形前先确认可分发授权与字体子集体积。
