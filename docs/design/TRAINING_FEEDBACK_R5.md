# 江湖训练体验 R5 · 执行方案

## 本轮范围

继续更新 `feat/jianghu-art-ui` / PR #7。面向测开初学者，把训练台整理为“执行 → 自报结果 → 核对证据”，并接入公共状态页面。延续 R3/R4 江湖视觉，不新增系统或自动学习决策。

## 设计

- 色彩：墨褐 `#1f1b15`、暖纸 `#fffcf6`、砂色 `#eee6d8`、赭金 `#79561e`、朱砂 `#8f382b`、玉绿 `#42624b`。颜色区分状态，同时必须有文字说明。
- 字体：艺术字仍限首屏；训练标题 Noto Serif SC，操作与正文 Noto Sans SC，命令 Cascadia Code/Consolas；沿用现有本地回退，不引入字体资源。
- 特征：训练台是一份可核对的实践记录。命令块作为视觉重心，结果与证据分层。编号只对应真实执行顺序。

```text
训练导航 / 版本与同步反馈
┌ 执行准备与命令 ─────────┬ 最新一次自报结果 ┐
│ 正常实现 → 故障自检     │ 基线 / 三项故障  │
│ 记录这次尝试（原表单）  │ SHA / CI / 复盘  │
└───────────────────────┴ 更早的记录 ──────┘
```

复核取舍：不增加游戏化分数、成功率仪表盘、自动运行代码或 AI 自动评分。复盘提示沿用现有故障说明，历史原文与全部证据入口保留。动效只服务操作反馈，不添加循环装饰。

## 三项实施

1. 练习验收：分开正常实现与故障自检命令；显式复制，失败时允许手动选择，不执行命令。最近一次自报结果优先展示，早期历史按需展开；已提供 CI 链接仍标记未核验。
2. 状态反馈：明确区分读取中、提交中、成功、失败；保持原 SHA、锁、校验和保存请求。失败保留当前表单，引导先显式读取核对，不自动重发 POST。
3. 公共/空白状态：统一加载、读取错误、404、训练无权限及训练空态的可用下一步。撤掉“所有本机草稿都不会丢失”的笼统承诺。当前 Next.js 16.3 的错误页使用 `retry()` 重新读取，而非只清空边界状态的 `reset()`；不显示原始异常细节。

本轮只接入以上页面，不声称已统一全部业务页面的空/错状态。

## 硬边界

不修改正式学习记录、课程/任务 ID、推荐/评分/复习算法、训练 schema/service/API、OAuth、权限、GitHub Adapter、CRUD、SHA 冲突保护、Markdown 安全、凭据拦截、限流及部署配置。不新增正式数据存储、浏览器持久化或远程资源。

仅为反馈展示增加临时 UI 状态。所有读取/提交仍走既有函数；复制只在用户点击后写剪贴板，测试用隔离模拟剪贴板。测试数据与截图均为合成记录。

不新增 PR、不自动合并、不用 skip/fixme 或大 timeout。测试通过后提交同一分支并核对远端 CI。

## 验收

- 命令文本准确，复制成功/拒绝/不支持均有反馈；不自动执行或提交。
- 最新结果与历史无遗漏，自报结果不伪装为 CI 成绩；正常实现未通过时清楚说明不能据此判断故障检出能力。
- 提交/读取状态区分、错误无假成功、请求失败不自动重发、当前表单保留；原并发与 SHA 测试保持。
- 访客无训练内容泄露，空态提供现有入口；错误重试调用框架 retry，异常原文不显示。
- 桌面/390px/320px、键盘和 reduced-motion；实际截图复核。
- lint、typecheck、unit、build、完整 E2E 和入门 Python 回归。

## 实施记录

本轮已完成三项实现：`CommandBlock` 提供显式复制与手动降级，`AttemptLedger` 分离最新记录与可展开历史，`SyncFeedback` 区分读取/提交与失败反馈。`StatePanel` 接入加载、读取错误、404、训练访问受限和训练空态。复习卡补充暂停、未到期与当天已作答的原因说明，不修改原调度规则。

本地最终回归：lint、typecheck、build、209/209 单元测试（21 个文件）、32/32 E2E 全部通过。新增 14 项单元/组件测试、3 项 E2E；原 29 项 E2E 完整保留，无 skip/fixme 或 timeout 放大。Python 使用已有虚拟环境，pytest 37/37；selfcheck 正确检出全部三类教学缺陷。教学故障的预期断言失败不代表回归失败，也不是学习者个人完成记录。

验收覆盖：复制成功/权限拒绝/不支持、键盘操作、最新与早期证据完整性、基线阻塞与漏检提示、显式读写状态、失败保留输入且不重发 POST、无假成功/残留 commit 链接、来源失效与复习历史、无浏览器持久化或学习进度变化、访客只读及真实 SHA 冲突。错误边界通过当前框架 `retry` 接口重读，不暴露异常原文。

真实 Chrome 截图已复核桌面、390px/320px 训练台、手机读取错误、404 与零时间预算空态。修正了训练短复盘框继承全局 300px 最小高度造成的过量留白，改为局部最小高度并保留拉伸；E2E 检查默认框高。深色命令块单独提高键盘焦点对比度。首轮新增 E2E 曾误匹配链接可访问名称中的空格，修正定位后完整复跑两次通过，未通过改业务或加超时规避。

截图来自隔离合成数据，由 `e2e/training-feedback.spec.ts` 生成到 `test-results/`；训练组件截图还附在 Playwright 报告中。组件裁图隐藏固定站头避免遮挡，页面截图与原有站头测试不隐藏。旧页面测试生成的快照恢复至本轮开始时的基线，避免无关的合成数据与日期变化混入提交。

README 已修正过时的“全站楷体”说明，增加 R3/R4/R5 设计入口。正式学习文件、课程/任务 ID、学习算法、训练 schema/service/API、安全与保存机制均未改动；生产构建后的生成类型文件无额外差异。

远端 Actions / Vercel 以 PR #7 对应提交状态为准，保持 Draft、不自动合并。线上人工体验、真实网络性能、原生浏览器 200% 缩放和跨设备字体仍属于上线前验收。本轮不引入字体分发或继续扩展课程与学习算法。
