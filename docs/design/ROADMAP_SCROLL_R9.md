## 交互与技术约束

1. 六站使用真实锚点链接；保留 `#task-*`、浏览器前进/后退、键盘焦点与原生 details。点选立即展开章节，不等动画结束。
2. 建议继续的任务仍由既有算法提供；“正在查看”只是浏览状态，不能改变或冒充学习进度。
3. SVG 只做装饰并从无障碍树移除，链接为真实 HTML。静态 HTML 中目录与正文可用；不声称既有 Next 流式站点完全无脚本可用。
4. 路径仅一次有限展开，其他效果优先 transform/opacity；无持续 JS 渲染循环、滚动劫持、视频、WebGL、指针尾迹或新动画库。
5. 动效开关覆盖本轮新增效果；系统 reduced-motion 优先。离屏或页面隐藏暂停，卸载清理 observer 和监听。相关 API 不可用时静态降级。
6. 手机采用纵向目录，无缩放/拖拽地图要求；320px、200% 重排宽度和键盘必须可用。链接保持足够触控区域。
