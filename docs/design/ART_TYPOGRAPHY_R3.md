# 江湖 UI · 已确认的艺术字体 R3

## 本次采用的设计

用户确认 R3 后，从已合并高清图片修复的 `origin/main`（`bcb136b`）建立 `feat/jianghu-art-ui`。保持 SDET Learning OS 与江湖主题，不改名，不复制 Adobe 素材。

- 首屏以两行“以代码为剑 / 以测试为眼”为视觉中心；华文行楷、400 字重，不伪粗、不描边、不加文字阴影。英文品牌使用 Georgia，降为辅助。
- 中文页面标题采用 Noto Serif SC；UI、表单与正文采用 Noto Sans SC；代码采用 Cascadia Code / Consolas。艺术字不进入学习正文和输入框。
- 手机独立场景区约 260px，文字在其下方；当前任务仍来自原有推荐结果。笔记、日课、作品和完整阶段入口均保留。
- 墨褐、暖纸、砂色、赭金、朱砂、玉绿延续原江湖题材。浅色阅读区去除纹理，阅读正文桌面 17px/30px、手机 16px/28px，桌面主栏最多 720px。
- 手机笔记目录复用已有 ResponsivePanel，默认收起，支持关闭、Escape 和目录跳转；不修改笔记解析、保存和鉴权。
- 只保留短入场与必要的 hover 反馈，移除全页内容入场。缩略图放大仅对鼠标设备生效，reduced-motion 关闭非必要动效。

本设计取代旧的“全站普通 UI 楷体”要求。依据是用户对 R2 阅读字体和 R3 艺术首屏的连续确认；章标题艺术字选项不启用。

## 不可越过的边界

1. GitHub Repository 仍是唯一正式业务数据源。无新增本地文件、localStorage、IndexedDB 或数据库业务持久化。
2. 不改课程内容、任务 ID、统计、推荐、评分和复习计算。
3. 不改 OAuth、权限、GitHub Adapter、CRUD、SHA 冲突保护、Markdown 安全、凭据拦截及限流。
4. 不变更 Vercel 配置、环境变量、正式内容分支或真实学习记录。
5. 复用原有高清图片，不新增远程媒体或字体请求，不上传系统字体文件。
6. 不跳过、删除验收或增加超时；只更新合法移动的任务入口定位器。
7. 分支提交与 PR 不等于上线；不得自动合并。

## 字体与可移植性

本版不捆绑或再分发字体。Windows 本机已有华文行楷、Noto Sans SC 与 Noto Serif SC，已通过真实 Chrome 截图检查排版；未安装对应字体的设备会按 CSS 字体栈回退，不能保证跨设备字形完全一致。

确需跨设备统一书法字形时，另行确认可分发授权、字体子集与体积方案，不从用户 Windows 字体目录复制商业字体。

## 回归与证据

基础/首页阶段：lint、typecheck、189 项单元测试、build 和 7 项图片/登录/导航 E2E 通过。

学习/阅读阶段：189 项单元测试、build 和 12 项相关 E2E 通过，随后根据截图将手机长目录改为现有抽屉；该补丁纳入最终全量回归。

新增 `e2e/art-ui.spec.ts` 验收：

- 1920、1440、1024、768、390、320px 首页；首屏题句、品牌与正文的字体角色、入口与图片。
- 1440、1024、768、390、320px 长笔记混排、栏宽、正文大小、目录抽屉与 Owner/Public 控件。
- 720 CSS px 模拟 1440px 在 200% 浏览器缩放时的可用宽度。此项只验证重排，不冒充原生浏览器菜单缩放测试；CSS style.zoom 不会正确更新媒体查询，因此不用于这项验收。
- 保留原有高清测试：DPR 1/2、实际下载像素、quality 85、单图 600,000 字节上限，以及可见图片加载检查。没有等待所有离屏图片 decode。

截图均使用隔离测试数据，不是用户学习成果。`docs/design/v4/` 是现有测试的固定输出目录，本次更新为 R3 实际渲染；旧版可从基线提交查阅。完整截图与测试记录不是单纯的 CSS 字体声明证明。

最终本地回归：`npm run lint`、`npm run typecheck`、`npm run test`（189/189）、`npm run build`、`npm run test:e2e`（26/26）均通过。Python 使用已有虚拟环境执行 pytest（37/37）及 selfcheck，成功检出 age-boundary、duplicate、status-code 三种教学缺陷；自检中的预期失败不是回归失败，也不是用户完成记录。

人工检查了首页桌面/手机、长笔记桌面/手机，以及路线、笔记列表、项目、项目详情、动态和作品集的 Chrome 截图。焦点色使用独立的 `#8f6b2f`，与暖纸/墨褐的计算对比度分别约 4.40/3.52；正文和辅助文字不用浅金。

远端 PR/CI 及预览仍需对当前提交验收。生产网络 LCP/CLS、原生浏览器 200% 菜单缩放和其他设备的字体外观不得依据本地开发服务器结果宣称通过；这些检查未完成前，不得把本地回归描述为最终上线验收。
