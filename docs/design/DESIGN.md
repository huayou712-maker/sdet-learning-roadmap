# SDET Learning OS 视觉方案

对象是准备测试开发求职的单人学习者。首页任务是找到当前学习阶段，并把今天的实践变成证据。

## 视觉决策

- 墨底 #1f1b15、纸张 #f1e7d3、沙色 #a08c69、暖金 #b58a3b、印朱 #8f382b、玉绿 #364a3b。
- 标题用系统宋体/衬线；操作用系统无衬线；数据与代码用 Consolas 等宽。不捆绑字体。
- 上部以 CSS 山形和夕照建立江湖氛围，下部以纸张面板承载学习任务。
- 签名元素是“十阶进路”：数字对应真实 Stage 顺序，串联从网络基础到 AI 应用测试的学习过程。
- 参考图只保存在设计文档中，不作为网页背景，不复制人物或影视形象。

桌面：导航 → 横向 Hero → 六项真实统计 → 路线 / 笔记 / 今日 → 项目。
手机：目录菜单 → 紧凑 Hero → 两列统计 → 单列卡片 → 单栏学习清单。

## 设计自检

米色衬线本身不是差异化，必须通过真实阶段编号、证据状态和学习档案来建立身份。去掉无功能装饰卡，不使用发光按钮和蓝紫渐变。保留可见键盘焦点，支持 reduced-motion。
